🇫🇷 **Français** | 🇬🇧 [English](README.en.md)

Ce site web présente l'ensemble des **propositions d'évolution** (Swift Evolution) officielles pour le langage Swift, telles que publiées par la communauté et l'équipe Apple.

## Objectif

L'objectif de ce site est de fournir un accès structuré et consultable à toutes les propositions d'évolution du langage Swift, classées par version. Il permet aux développeurs de :

- **Rechercher** un sujet ou une fonctionnalité spécifique via la barre de recherche intégrée.
- **Parcourir** les propositions par version de Swift.
- **Comprendre** l'évolution du langage dans le temps, de ses premières versions stables jusqu'aux dernières avancées.

## Comment naviguer

Vous avez deux options pour explorer le contenu :

1. **Recherche** : Utilisez la barre de recherche en haut de la page pour trouver un sujet qui vous intéresse.
2. **Navigation par version** : Cliquez sur une version de Swift dans la liste ci-dessus pour accéder à toutes les propositions associées.

## Structure du site

Chaque proposition d'évolution est documentée avec :

- **Titre officiel** de la proposition (SE-XXXX)
- **Lien vers la proposition originale** sur le dépôt GitHub
- **Résumé** expliquant le problème et la solution
- **Exemples de code** avant et après l'application de la proposition

> ⚠️ **Avertissement** : Ce contenu a été généré par une IA. Il peut contenir des erreurs. Vérifiez les informations.

## Internationalisation

Ce site est rédigé en **Français**. Cependant, un mécanisme de traduction automatique est disponible pour permettre aux utilisateurs de consulter le contenu dans d'autres langues.

- **Langue par défaut** : Français
- **Traduction automatique** : Activez le sélecteur de langue dans la barre de navigation pour traduire les propositions dans votre langue.
