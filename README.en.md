This website presents the complete set of official **Swift Evolution** proposals published by the community and Apple.

## Objective

The goal of this site is to provide structured and searchable access to all Swift evolution proposals, classified by version. It allows developers to:

- **Search** for a specific topic or feature using the integrated search bar.
- **Browse** proposals by Swift version.
- **Understand** the evolution of the language over time, from its first stable versions to the latest advancements.

## How to Navigate

You have two options to explore the content:

1. **Search**: Use the search bar at the top of the page to find a topic of interest.
2. **Version Navigation**: Click on a Swift version in the list above to access all associated proposals.

## Site Structure

Each evolution proposal is documented with:

- **Official Title** of the proposal (SE-XXXX)
- **Link to the original proposal** on the GitHub repository
- **Summary** explaining the problem and the solution
- **Code examples** before and after the application of the proposal

## Internationalization

This site is primarily written in **French**. However, an automatic translation mechanism is available to allow users to view the content in other languages.

- **Default Language**: French
