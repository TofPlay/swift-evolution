# Swift Evolution

[![GitHub](https://img.shields.io/badge/GitHub-TofPlay/swift--evolution-blue?logo=github)](https://github.com/TofPlay/swift-evolution)
[![Live Site](https://img.shields.io/badge/Live%20Site-Swift%20Evolution-brightgreen)](https://tofplay.github.io/swift-evolution/)

A curated collection of **Swift Evolution (SE)** proposals, organized by Swift version, with AI-generated summaries and code examples.

## What is this?

This site is a community-maintained, searchable index of all [Swift Evolution proposals](https://github.com/swiftlang/swift-evolution/tree/main/proposals), the official source for changes to the Swift programming language.

Each proposal is summarized with:
- **A clear description** of the feature or change
- **Code examples** showing before/after usage
- **The Swift version** where it becomes available
- **Links** to the original proposal on GitHub

> ⚠️ **Disclaimer**: This content has been generated by AI. It may contain errors. Always verify information against the [official Swift Evolution proposals](https://github.com/swiftlang/swift-evolution/tree/main/proposals).
