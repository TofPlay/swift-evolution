## Objectif

L'objectif de ce site est de fournir un accès structuré et consultable à toutes les propositions d'évolution du langage Swift, classées par version. Il permet aux développeurs de :

- **Rechercher** un sujet ou une fonctionnalité spécifique via la barre de recherche intégrée.
- **Parcourir** les propositions par version de Swift.
- **Comprendre** l'évolution du langage dans le temps, de ses premières versions stables jusqu'aux dernières avancées.
